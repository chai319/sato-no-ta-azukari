# 里の田あずかり（v0.2f）

高校「生物」窒素同化・窒素循環を学ぶ、iPad／ブラウザ向け稲作シミュレーション教材。

## 概要
- **対象**: 高等学校「生物」受講生徒（iPad / PC / Chromebook）
- **テーマ**: 稲作の一年を通じて、土壌中および植物体内の窒素動態（有機態窒素、アンモニウム態窒素、硝酸態窒素、脱窒、施肥、食物連鎖、収量、環境負荷）を探究・体感するシミュレーション。
- **特徴**:
  - 一周目：数値や専門用語を隠し、五感や兆し（葉の色、泡、土の様子）を手がかりに手探りで育てる。
  - 感想戦：収量や窒素のゆくえ（サンキー図）、土の断面（酸化層・還元層）を振り返り、科学的に考察。
  - 二周目・三周目：前年の土壌窒素（地力 carryover）や手持ち銭を引き継ぎ、仮説を持って再挑戦。
  - セーブ機能（localStorage）対応：途中でブラウザを閉じても「つづきから」で前年の土と記録を引き継いで再開可能。
